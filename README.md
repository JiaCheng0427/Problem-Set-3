# ECON 5200 — Problem Set 3

## Project Overview

This project is for ECON 5200: Causal Machine Learning & Applied Analytics.

The assignment focuses on Difference-in-Differences (DiD) methods and the problems that can arise when treatment is introduced at different times.

## Main Topics

- Replicating the Card and Krueger minimum wage study
- Building a simulated panel with 40 counties and 8 regional boards
- Estimating treatment effects using two-way fixed effects (TWFE)
- Examining Goodman-Bacon decomposition and forbidden comparisons
- Estimating treatment effects with not-yet-treated control groups
- Event study and parallel trends
- Comparing clustered standard errors
- Wild cluster bootstrap inference

## Tools Used

Python, NumPy, Pandas, Matplotlib, SciPy, and Statsmodels.
